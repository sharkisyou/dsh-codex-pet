# 宠物透明区域点击穿透（包围盒方案）

## 背景与问题

桌宠窗口（Tauri v2，`transparent: true`，`alwaysOnTop`）的命中测试是**矩形级**的：
透明像素只是 DWM 合成时不渲染，窗口仍是一个完整矩形，且 `.pet-stage` 占满整个视口
（`style.css` 注释明确"必须占满整个窗口"）。因此点击宠物周围透明区域时，事件被
webview 消费，**不会穿透到底下的桌面图标**。

## 决策（2026-09-08，用户选定）

采用**包围盒简化版**：以精灵当前帧的不透明外接矩形（bounding box）作为交互区域，
bbox 内正常交互，bbox 外（窗口其余部分）点击穿透。

- 不采用像素级扫描线掩码：实现成本高（约 150 行 TS+Rust），收益是两侧空白也精确穿透。
- 不采用全窗常驻穿透：宠物本体也点不到了。

## 设计要点

1. **TS 侧推送 hitbox**：renderer 知道当前帧、缩放（zoom）与 devicePixelRatio，可把精灵
   不透明外接矩形换算成**窗口物理坐标**，经 `invoke('set_pet_hitbox', { x, y, w, h })` 推给
   Rust。推送时机：精灵加载/帧变化、`applyZoom()`、窗口尺寸变化。
2. **Rust 侧轮询切换**：约 50-100ms 轮询 `GetCursorPos` → 换算到宠物窗口本地物理坐标 →
   命中 bbox 则 `set_ignore_cursor_events(false)`，否则 `true`。穿透时窗口收不到任何鼠标
   事件，因此**不能依赖前端事件切回**，必须轮询。
3. **拖拽钉住（关键坑）**：手动拖拽进行中，光标快速移动会甩出 bbox → 若此时切穿透，拖拽
   立即中断。前端在拖拽开始/结束时 `invoke('set_pet_dragging', { dragging })`，Rust 侧
   dragging=true 期间钉住 `ignore_cursor_events(false)`。
4. **托盘角标必须保留可点**：`#activity-tray-wrap` 位于窗口顶部透明区，穿透后角标点击
   会失效。hitbox 应取**精灵 bbox ∪ 托盘角标矩形**（前端同样可算出角标的
   `getBoundingClientRect()` 物理坐标）。
5. **已知取舍**：bbox 内的非精灵透明像素依旧点不穿（例如精灵两侧留白）；多显示器跨
   DPI 拖动时换算有轻微漂移，松手重抓即恢复。

## 验收标准

1. 点击宠物周围透明区域 → 底下桌面图标正常收到点击
2. 点击宠物本体（点击技能——注：460d0d1 已移除点击动作，交互为右键菜单）、拖拽、右键菜单不变
3. 托盘角标仍可点击展开/收起
4. 快速拖拽不中断（拖拽钉住生效）
5. 缩放（zoom）与窗口尺寸变化后 bbox 跟随
6. pet server 不可达（待机剪影形态）时穿透行为不异常（剪影本身也有 bbox）
