# 04 — 桥接插件：WS 客户端 + 事件翻译 + 重连

**What to build:** 把 DSH 插件瘦身为桥接插件：作为 WebSocket 客户端连接桌宠（默认端口或 `DSH_PET_URL`），自动连接并断线重连；把 DSH 的会话活动翻译成线协议事件推送过去，包括提问独立事件、审批并发计数、子代理归父解析、会话目录与握手快照、会话同步清理；移除浏览器 overlay、RPC 与宠物库代码。

**Blocked by:** 02 — pet-protocol：线协议包

**Status:** ready-for-agent

- [ ] 插件作为 WS 客户端能连上桌宠服务端，连接失败自动重试、断线重连。
- [ ] DSH 会话活动（状态/错误/工具/审批/提问/子代理）被翻译为对应线协议事件，载荷正确并带来源工具名。
- [ ] 连接握手时发送当前会话快照；重连后重新握手。
- [ ] 浏览器 overlay / 宠物库 / 宠物 RPC 相关代码已移除，插件只做桥接。
- [ ] 用 mock ctx 的集成测试覆盖事件翻译与重连行为。
