# Pet

一个常驻桌面的动画宠物（桌宠）与 DeepSeek Harness 插件（桥接插件）组成的双部件系统：桌宠在浏览器外独立运行、通过动画反映会话状态；桥接插件把会话活动转发给桌宠。

## Language

**桌宠 (Desktop Pet)**:
独立运行于桌面（浏览器外）的动画宠物应用；它常驻桌面、自管宠物库与设置，作为服务端接收各 agent 工具推送的活动，并自行聚合展示。
_Avoid_: 桌面挂件, 小工具

**宠物 (Pet)**:
动画角色本身——桌宠应用内渲染的那只宠物，通过播放动画反映当前会话状态。
_Avoid_: 伙伴, mascot

**宠物包 (Pet Package)**:
定义一只宠物外观与动画的资源包——一份元数据文件加一张帧图集，与 Codex 桌面宠物包格式兼容。
_Avoid_: 皮肤, 主题

**状态 (State)**:
宠物动画所绑定的会话状态，如空闲、工作、等待、失败。
_Avoid_: 模式, 阶段

**会话 (Session)**:
一次独立对话/任务；在多会话场景中，宠物跟踪的顶层会话，子代理活动归入其父会话。
_Avoid_: 聊天, 任务, 对话

**子代理 (Subagent)**:
由某个会话派生的委托执行，自身不是托盘条目；桥接只跟踪顶层会话，子代理的实时事件在转发前丢弃，父会话以「运行中」表示它的存在。
_Avoid_: 子会话, 下级 agent

**多会话 (Multi-session)**:
宠物跨多个会话跟踪活动，并同一时刻只展示优先级最高的那个会话。
_Avoid_: 多标签, 多窗口

**活动托盘 (Activity Tray)**:
列出当前有活动的会话的浮层；用户可点击某项切换到对应会话。
_Avoid_: 会话列表, 通知中心

**活动会话 (Active Session)**:
处于非空闲状态的会话，包括需要输入、受阻、就绪、运行中。
_Avoid_: 打开的会话, 最近会话

**需要输入 (Needs input)**:
会话正在等待用户批准、回答或其他决定。
_Avoid_: 等待中, 待处理

**受阻 (Blocked)**:
会话失败或遇到系统错误。
_Avoid_: 错误, 故障

**就绪 (Ready)**:
会话已完成且有未读的新活动；工作区中以绿点提示。
_Avoid_: 完成, 待查看

**运行中 (Running)**:
会话正在积极工作。
_Avoid_: 工作中, 处理中

**唤醒 (Wake)**:
令宠物出现并开始跟随会话状态；反之称为隐藏。
_Avoid_: 启动, 打开

**宠物库 (Pet Library)**:
桌宠直接读取的 Codex 宠物目录（`~/.codex/pets/`，只读）；宠物包无需复制即可被桌宠选用。
_Avoid_: 商店, 仓库

**宠物市场 (Pet Market)**:
桌宠内打开外部宠物画廊（如 petdex.dev/zh）的入口；宠物包需经 Codex 自行安装后才会出现在宠物库，桌宠不负责导入。
_Avoid_: 商店, 商城

**导入 (Import)**:
（已废弃）桌宠不再复制宠物包；宠物库直接取自 Codex 宠物目录。
_Avoid_: 安装, 装载

**桥接插件 (Bridge Plugin)**:
DeepSeek Harness 里的插件部件：监听会话事件，把活动转发给桌宠；不在插件内管理宠物库或渲染宠物。
_Avoid_: 连接器, 转发器

**来源工具 (Source Tool)**:
向桌宠推送活动的事件来源，如 DSH（经桥接插件）、Codex、Claude 或其他 agent 工具。每个事件携带来源名称；会话身份按 (来源, 会话) 复合区分，避免不同工具的会话 id 互相冲突。
_Avoid_: agent, 提供方

**点击技能 (Click Skill)**:
点击宠物本体触发的宠物包内置技能动画，按宠物包定义的顺序循环播放。
_Avoid_: 招式, 彩蛋
