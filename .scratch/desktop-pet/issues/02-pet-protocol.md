# 02 — pet-protocol：线协议包（schema + 类型 + 校验 + 版本/端口常量）

**What to build:** 发布一份公开契约包：把桌宠线协议的全部消息——信封、握手与快照、会话状态/错误、工具、审批、提问、子代理、会话同步、会话目录、反向打开会话——用 JSON Schema 描述，构建时生成 TypeScript 类型并提供运行时校验；包内带协议版本号与默认端口常量，供桥接插件与桌宠共同消费。

**Blocked by:** 01 — 单仓库脚手架与分支

**Status:** ready-for-agent

- [ ] 协议信封与全部事件都有 JSON Schema，第三方可直接阅读。
- [ ] 构建时能从 JSON Schema 生成 TS 类型（无手写漂移），类型与 schema 一致性检查通过。
- [ ] 运行时校验：合法消息通过、非法消息被拒绝的测试通过。
- [ ] 版本号（URL 路径 `/v1` + 握手）与默认端口常量已定义。
- [ ] 每个事件类型声明 `agent`（来源工具）字段与会话复合键约定。
